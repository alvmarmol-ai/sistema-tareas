# 🎮 Catálogo de Videojuegos - Next.js 16 + Supabase

Proyecto desarrollado como actividad evaluada demostrando competencias con Next.js App Router y servicios serverless.

## 🚀 Tecnologías empleadas
- Next.js 16 (App Router)
- Supabase (PostgreSQL & Serverless)
- Tailwind CSS
- Vercel

## ⚙️ Instalación Local
1. Clona el repositorio: `git clone <URL_REPOSITORIO>`
2. Instala dependencias: `npm install`
3. Configura el archivo `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=tu_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_key
